WHAT IS CAESAR CIPHER

The Caesar cipher is one of the oldest encryption techniques, named after Julius Caesar who used it to protect military communications. It works by shifting each letter in the plaintext by a fixed number of positions in the alphabet.

Example:

Plaintext: HELLO
Shift: 3
Encrypt step-by-step:
H -> K
E -> H
L -> O
L -> O
O -> R
Ciphertext: KHOOR

HOW IT WORKS

Each letter is shifted forward (encrypt) or backward (decrypt) by the chosen shift value in the Caesar Cipher The algorithm works only on alphabetic characters while numbers spaces and symbols remain unchanged .
With shift (3) A -> D , B -> E , and Z -> C This shows how every letter moves a fixed number of steps in the alphabet .
The alphabet is treated like a circle so after Z it goes back to A This is called wrap around and is handled using modular arithmetic It ensures that calculations like Z + 3 do not go outside the alphabet range but instead return valid letters within A-Z .
Because the same shift is applied to every letter the pattern remains consistent which is why Caesar Cipher is a simple substitution cipher but still useful for understanding basic encryption concepts .

FORMULA

Encrypt: C = (P + shift) mod 26
Decrypt: P = (C - shift + 26) mod 26

OUTPUT FREQUENCY
