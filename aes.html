WHAT IS AES?

AES (Advanced Encryption Standard, 2001) replaced DES as the global symmetric encryption standard. It operates on 128-bit blocks using substitution-permutation networks, with a 128-bit key and 10 rounds. It has no known practical attacks.

KEY EXPANSION

AES derives a set of round keys from the original key using a key schedule. For AES-128 this produces 11 round keys (one initial + 10 per round). Each round key uses SubWord (S-box lookup), RotWord (byte rotation), and XOR with Rcon (round constants).

SUBBYTES

Each of the 16 state bytes is independently replaced by a value from the AES S-box — a fixed 256-entry lookup table derived from the multiplicative inverse in GF(2⁸) followed by an affine transformation. This is the non-linear step that provides confusion.

state[i][j] = S_BOX[state[i][j]]

SHIFTROWS

The four rows of the 4×4 state matrix are cyclically shifted left: row 0 by 0, row 1 by 1, row 2 by 2, row 3 by 3 bytes. This ensures that bytes from different columns mix across rounds, providing diffusion across the entire block.

MIXCOLUMNS

Each column of 4 bytes is treated as a polynomial over GF(2⁸) and multiplied by a fixed matrix. This spreads each input byte to affect all 4 output bytes of the column — creating full diffusion so a single-bit change affects the entire state after just 2 rounds.

c(x) = a(x) · M(x) mod (x⁴+1)

ADDROUNDKEY

The current state is XORed with the round key (a 128-bit portion of the expanded key). This is the only step that uses the secret key. Applied before round 1 and at the end of each round (including the final round which skips MixColumns).

state ⊕= roundKey[i]
