WHAT IS RSA?

RSA (Rivest-Shamir-Adleman, 1977) is the world's most widely used public key cryptosystem. It uses a key pair a public key anyone can use to encrypt, and a private key only the owner uses to decrypt. Security rests on the hardness of factoring large numbers.

KEY GENERATION

Choose two distinct primes p and q. Compute n = p·q (the modulus) and Euler's totient φ(n) = (p-1)(q-1). Pick public exponent e with gcd(e, φ) = 1. Compute private exponent d as the modular inverse of e mod φ.

ENCRYPTION & DECRYPTION

Each character is treated as its ASCII code m. It must satisfy m < n.

Encrypt: C = mᵉ mod n
Decrypt: m = Cᵈ mod n

Public key: ( e , n )

WHY ASYMMETRIC?

Unlike Caesar or Rail Fence, RSA uses two different keys. Encrypting with the public key produces ciphertext that only the private key can decode. This enables secure communication without ever sharing a secret key, making RSA fundamental to HTTPS, SSH, and digital signatures.

MODULAR EXPONENTIATION

Computing mᵉ mod n for large numbers uses the fast square and multiply (binary exponentiation) algorithm, making it efficient even for huge exponents , while the inverse operation (discrete log / factoring) remains hard.
