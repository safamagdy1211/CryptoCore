WHAT IS THE AFFINE CIPHER?

The Affine cipher is a monoalphabetic substitution cipher that uses a mathematical formula instead of a plain shift. It requires two keys — a (multiplier) and b (shift) — making it more complex than Caesar.

THE FORMULAS

Each letter maps to its index (A=0 … Z=25), then the formula is applied and the result maps back to a letter.

Encrypt: C = (a · P + b) mod 26
Decrypt: P = a⁻¹ · (C − b) mod 26
Condition: gcd(a, 26) = 1

KEY CONSTRAINT

Key a must satisfy gcd(a, 26) = 1 so that the modular inverse a⁻¹ exists. This ensures every letter maps to a unique output — without it, decryption is impossible. Key b can be any value 0–25.
