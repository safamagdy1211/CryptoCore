WHAT IS SHA-256?

SHA-256 (Secure Hash Algorithm 256-bit) is a cryptographic hash function from the SHA-2 family, published by NIST in 2001. It produces a fixed 256-bit (32-byte) digest from any input, used in TLS, Bitcoin, code signing, and password hashing.

ONE-WAY PROPERTY

Unlike ciphers, SHA-256 is not reversible. Given a hash, it is computationally infeasible to recover the original input. Even a single character change produces a completely different 256-bit output — the avalanche effect.

THE CORE OPERATIONS

Each 64-round compression uses bitwise operations on 32-bit words:

Ch(e,f,g) = (e AND f) XOR (NOT e AND g)
Maj(a,b,c) = (a AND b) XOR (a AND c) XOR (b AND c)
Σ0(a) = ROTR²(a) XOR ROTR¹³(a) XOR ROTR²²(a)
Σ1(e) = ROTR⁶(e) XOR ROTR¹¹(e) XOR ROTR²⁵(e)

COLLISION RESISTANCE

Finding two different inputs that produce the same hash requires ~2¹²⁸ operations — considered computationally impossible with current hardware. The 2²⁵⁶ possible outputs make brute-force attacks infeasible for the foreseeable future.

MERKLE–DAMGÅRD STRUCTURE

SHA-256 processes input in 512-bit blocks using the Merkle–Damgård construction. Each block updates 8 hash registers (A–H, each 32-bit). After all blocks are processed, the registers are concatenated to form the 256-bit final digest.

⊕ USES IN THE REAL WORLD

SHA-256 is the backbone of Bitcoin proof-of-work, TLS/HTTPS certificate signatures, code signing (macOS, Windows), Git commit hashes, and password hashing (PBKDF2, bcrypt uses SHA internally).
