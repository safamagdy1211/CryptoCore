WHAT IS COLUMNAR TRANSPOSITION?

Columnar Transposition is a classical cipher that rearranges the plaintext by writing it row-by-row into a grid, then reading out the columns in the order dictated by a keyword. No letters are changed — only their positions.

HOW IT WORKS

Write the message across rows, each row as wide as the keyword. Number the columns by the alphabetical rank of each keyword letter. Read each column top-to-bottom in that ranked order to form the ciphertext.

cols = length of keyword
rows = ⌈message_length / cols⌉
pad = rows × cols − msg_len
order = argsort(keyword letters)

EXAMPLE — KEY: "CAB"

For HELLOWORLD with key CAB:

Keyword: C A B
Order: 2 0 1
─────────────────
Row 0: H E L
Row 1: L O W
Row 2: O R L
Row 3: D X X ← padded
─────────────────
Col A(0): E O R X
Col B(1): L W L X
Col C(2): H L O D
Result: EORX LWLX HLOD
