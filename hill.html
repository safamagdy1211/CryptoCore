WHAT IS THE HILL CIPHER?

The Hill cipher is a polygraphic substitution cipher based on linear algebra. It encrypts blocks of letters at once using matrix multiplication, making it stronger than simple letter-by-letter ciphers like Caesar or Affine.

THE FORMULAS

Letters are converted to numbers (A=0…Z=25), grouped into column vectors, then multiplied by the key matrix K.

Encrypt: C = K · P (mod 26)
Decrypt: P = K⁻¹ · C (mod 26)
Condition: gcd(det(K), 26) = 1

KEY CONSTRAINT

The key matrix K must be invertible mod 26, meaning gcd(det(K), 26) = 1. This ensures the modular inverse matrix K⁻¹ exists, enabling decryption. Non-square or singular matrices cannot be used.
