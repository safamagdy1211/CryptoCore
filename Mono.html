WHAT IS IT?

A substitution cipher where each letter in the plaintext is replaced by another letter using a fixed key a permutation of the 26-letter alphabet.

HOW DOES IT WORK?

Each letter is mapped to another letter consistently throughout the entire message using the 26-character key string.

WHERE IS IT USED?

Historically used in ancient encryptions and educational tools to demonstrate basic cryptographic concepts and frequency analysis.
