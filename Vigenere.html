CIPHER FORMULAS
Encrypt: C = (P + K) mod 26

C = cipher, P = plain, K = key shift (A=0 … Z=25). Keyword repeats cyclically over letters only.

What is Vigenère?

The Vigenère cipher is a polyalphabetic substitution cipher invented by Blaise de Vigenère in 1553. Unlike Caesar which uses a fixed shift, Vigenère uses a keyword that defines different shifts for each character.

Encryption Formula

Each plaintext letter is shifted by the numeric value of the corresponding keyword letter (A=0, B=1, ..., Z=25). The keyword repeats cyclically.

C = (P + K) mod 26
C: cipher, P: plain, K: key shift
Decryption Formula

Decryption reverses the shift by subtracting the key value. The modulo ensures wrap-around within the 26-letter alphabet.

P = (C - K + 26) mod 26
C: cipher, P: plain, K: key shift
Key Expansion

The keyword repeats to match the length of the plaintext. Only letters are encrypted ,but numbers, spaces, and punctuation are kept unchanged.

Key: S E C R E T S E C R ...
Msg: H E L L O W O R L D ...
How It Works

For each plaintext letter, find the keyword shift and apply modular arithmetic. For decryption, subtract the shift instead. Non alphabet characters pass through unchanged.
