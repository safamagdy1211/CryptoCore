WHAT IS OTP?

The One-Time Pad is a symmetric encryption scheme proven to be perfectly secure by Claude Shannon in 1949. Each byte of the message is XOR'd with a corresponding byte from the key, producing ciphertext that reveals no information without the key.

THE XOR OPERATION

XOR (⊕) is the core operation: bits that are equal yield 0, different bits yield 1. Applied byte-by-byte:

Encrypt: C = P ⊕ K
Decrypt: P = C ⊕ K
Property: X ⊕ X = 0, X ⊕ 0 = X

THE THREE RULES

OTP security requires exactly three conditions: (1) the key must be truly random, (2) the key must be at least as long as the message, and (3) the key must never be reused. Breaking any rule destroys perfect secrecy.

WHY UNBREAKABLE?

For any ciphertext, every possible plaintext of that length is equally probable — there is no statistical information to attack. Even with infinite computing power, an attacker gains zero knowledge about the message. This is called perfect secrecy.
